# Contexto del proyecto
En la actualidad, muchas personas tienen dificultades para organizar y controlar sus finanzas, ya que suelen ser muy desordenadas y con poca claridad. Por ello, surge nuestro proyecto de una app de manejo financiero que centraliza la información y brinda recomendaciones para mejorar la toma de decisiones, utilizando tecnologías web bajo un enfoque full stack.
